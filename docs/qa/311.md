# QA Script — Issue #311: Safe GIS reference-file conversion

## Scope

Issue #311 is Child A of #247. It adds a pure, UI-independent browser import boundary that converts `.geojson`/`.json`, `.kml`, `.kmz`, one-dataset zipped Shapefiles, and `.gpx` into canonical #279 vector `AuthoredLayer`s.

This QA validates:

- direct GeoJSON delegation through the existing #222 parser/normalizer;
- native-browser KML/GPX parsing with `@tmcw/togeojson` and no external-resource fetching;
- bounded KMZ/Shapefile ZIP inspection and extraction, including ZIP64/encryption/compression/nesting/path/CRC/size protections;
- deterministic KMZ KML selection;
- Shapefile dataset/sidecar discovery, DBF bounds/properties/date coercion/CPG behavior, and fail-closed CRS handling;
- WGS84, Web Mercator, WGS84 / UTM 23S, and SIRGAS 2000 / UTM 23S reprojection accuracy;
- all-or-nothing sequential batches, canonical #279 error propagation, and caller cancellation at every important phase;
- no network access for imported KML/KMZ/GPX/Shapefile content;
- converter dependency lazy loading and single runtime `proj4` resolution;
- no current production-entry bundle growth before Child B wires this subsystem into MapScreen.

There is intentionally **no production UI for these new formats in #311**. UI picker/drop/error localization and persisted draft insertion belong to Child B (#312). Human QA for this issue is therefore technical/browser QA rather than a click-through import workflow.

2. `npm ls proj4 --all` resolves one runtime `proj4` version; `shpjs` must be deduped to it.

5. Chromium, Firefox, and WebKit each convert KML, GPX, KMZ, and zipped Shapefile inputs through real browser APIs.

## Acceptance checklist

### 1. Public format contract

Confirm the public module exports the reviewed extension/accept constants and detects supported final filename extensions case-insensitively. MIME type must never override an unsupported or mismatched extension.

Unsupported GeoPackage, FileGDB, raster GIS containers, loose Shapefile components, and nested ZIP/KMZ inputs must remain unsupported.

### 2. Direct GeoJSON and canonical boundary

Confirm:

- direct `.geojson`/`.json` uses #222 `readGeoJsonOverlayFile` behavior;
- the exact 5 MiB source limit is accepted and 5 MiB + 1 byte is rejected;
- #222 parser/normalizer errors map to structured Child A conversion errors;
- #279 per-layer and batch validation errors surface as `kind: 'canonical'` without parallel reimplementation;
- multi-file batches preserve selection order and return no partial layer array on any failure.

### 3. XML/KML/GPX safety

Confirm malformed XML, invalid UTF-8, non-UTF-8 declarations, `DOCTYPE`/`ENTITY`, wrong roots, markup-token overflow, element overflow, and depth overflow fail with stable structured errors.

Confirm KML:

- preserves supported Point/LineString/Polygon/MultiGeometry content and ordinary metadata;
- skips null geometry;
- drops GroundOverlay and NetworkLink pseudo-features;
- never requests icon hrefs, schemas, styles, NetworkLinks, or other external resources;
- returns `no-supported-geometry` when only unsupported/dropped constructs remain.

Confirm GPX waypoint/route/track conversion and ordinary properties.

### 4. KMZ and archive boundary

Confirm deterministic selection:

- unique root `doc.kml` wins;
- otherwise one KML anywhere is accepted;
- none -> `kmz-no-kml`;
- multiple without unique root `doc.kml` -> `kmz-ambiguous-kml`.

Confirm the archive safety matrix rejects:

- more than 64 entries while exactly 64 is accepted;
- declared or actual entry data above 10 MiB;
- declared or actual aggregate data above 20 MiB;
- ZIP64;
- encrypted entries;
- compression methods other than STORE/DEFLATE;
- nested `.zip`/`.kmz`;
- unsafe/path-traversal names;
- malformed archives, corrupt streamed bodies, CRC mismatches, and inconsistent declared/emitted sizes.

Stream cancellation must be bounded even when `reader.cancel()` never settles.

### 5. Shapefile boundary

Confirm one and only one `.shp` dataset is accepted. `.dbf` and `.prj` are mandatory; `.shx` is optional/inert and `.cpg` is optional. Duplicate case-insensitive companions must fail as ambiguous.

Confirm:

- DBF declared record count >50,000 fails before conversion;
- `.prj`/`.cpg` text metadata is bounded to 64 KiB;
- CPG decoding is passed through to `shpjs` (fixture proves Windows-1252 `Café`);
- DBF type-`D` dates become `YYYY-MM-DD` strings;
- arbitrary non-Date class instances are not silently flattened/stringified and reach canonical rejection;
- non-finite unsupported property values fail through the canonical boundary.

### 6. CRS fail-closed matrix

The `.prj` is mandatory. No online EPSG lookup, grid download, or fallback assumption is allowed.

The synthetic control-point fixtures must transform to WGS84 within absolute longitude/latitude error `<= 1e-5` degrees for:

- WGS84 geographic;
- Web Mercator;
- WGS84 / UTM zone 23S;
- SIRGAS 2000 / UTM zone 23S.

Grid-dependent CRS text such as `+nadgrids`, `PARAMETERFILE`, or `NTv2` must fail closed.

### 7. Cancellation and resource cleanup

Confirm AbortError propagation:

- before the first read;
- between sequential files;
- during archive stream reading;
- after synchronous DOM parsing;
- after Shapefile conversion returns;
- before final canonical success is returned.

The archive reader must be cancelled/released on stream failure/abort, and cleanup must have a finite timeout so a hostile/misbehaving `cancel()` cannot hang the import.

### 8. Privacy/network invariants

For malicious local KML, KMZ, GPX, and Shapefile fixtures, spies must show no calls to `fetch`, XMLHttpRequest `open`/`send`, or `Image` construction.

The implementation must add no endpoint, cloud conversion, EPSG lookup, telemetry payload containing source bytes/geography, source-file persistence, or external-resource resolution.
